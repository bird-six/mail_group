邮件群发助手 3.2.0 · Windows 桌面版

一、启动
Windows 10 / 11 64 位系统，无需安装 Python、Node.js 或配置开发环境。
免安装：双击 MailGroup-3.2.0-x64-portable.exe。
安装版：双击 MailGroup-3.2.0-x64-nsis.exe，按提示安装，然后打开桌面快捷方式。
两种版本使用同一份数据，建议选择其中一种。启动时会自动打开应用窗口，不需要浏览器。
窗口没有系统标题栏，可拖动顶部深色区域；右上角可以最小化、最大化和关闭。

二、第一次使用
1. 打开“邮箱集群”，添加自己的邮箱、SMTP 授权码、服务器和端口并启用。
2. 打开“目标邮箱”，粘贴或导入收件邮箱，检查要发送的对象处于启用状态。
3. 打开“邮件内容”，填写主题、正文，选择纯文本或 HTML，添加所需附件。
   邮件模板会连同附件一起保存；模板附件加载失败时会阻止发送。
   多模板随机发送：勾选多个模板（支持全选），页面自动切换为“随机使用选中模板”。
   每位收件人独立、等概率地抽取一个模板，可能重复抽中同一模板。
   主题、正文和附件始终配套；当前编辑器中未保存的内容不会混入随机发送。
   清空选择后不能发送；点击“载入编辑”或切换“当前编辑内容”可回到原来的编辑方式。
4. 回到“首页”，确认内容和收件人后点击“开始群发”。
5. 首页可查看任务进度和详情，包括每个收件人的邮件主题；“数据面板”可查看统计及失败原因。

任务创建时会固定每位收件人的模板并保存副本。重启恢复不重新抽取，删除原模板也不影响已有任务。
从 3.0 升级会自动备份数据库为 before-v3.1.sqlite3，升级后请继续使用新版程序。

发送成功的收件人自动禁用，避免再次批量发送。确需再次发送时请手动启用。
同一发送邮箱的相邻邮件保持 20～40 秒间隔，多个任务之间也遵守此间隔。
关闭窗口时，如有活动任务会提示暂停；重启后从任务列表继续剩余任务。
异常断电等情况中，显示“结果待核对”的邮件可能已经送达。默认恢复不会重发这些邮件，
核对邮箱实际记录后再决定是否点“重试待核对”，以免重复投递。

三、邮件汇总
打开“邮件汇总”，点击“同步全部邮箱”，可统一查看收件箱、已发送邮件。
在顶部选择账号、收件/已发送类型，或搜索主题、发件人、收件人；点击邮件查看正文。
本应用成功发送的邮件也会保留在汇总中，标记为“本机发送”，点“刷新列表”即可查看。
同封已识别的远程副本自动合并；旧版记录可能同时显示两个来源。

先在服务商处开启 IMAP，使用与发送相同的授权码；常见邮箱自动识别服务器。
需要手动配置时，进入“邮箱集群 → 编辑 → IMAP 设置”，填写地址、端口和已发送文件夹。
默认 SSL/TLS 993，也支持 STARTTLS。暂不支持仅允许 OAuth 登录的账号。
每次为每个账号的收件箱、已发送文件夹各补充最多 100 封，优先同步新邮件；
继续点击同步可补全历史。单账号失败不影响其他账号，关闭群发的账号也会同步。
正文和列表仅缓存在本机。查看不会修改原邮箱已读状态，不加载远程图片。
已查看的正文可离线阅读；附件只展示名称，请到原邮箱打开。
大邮件最多读取 10 MiB、展示 50 万字符，内容截断时会提示。
修改 IMAP 配置或授权码需重新同步；更换邮箱地址或删除账号会移除对应汇总缓存。

四、数据与升级
数据保存在 %APPDATA%\MailGroup\data。
点击窗口右上角文件夹图标可打开数据目录。
备份前关闭应用，复制整个 data 文件夹即可，包括数据库及附件。
升级或重新放置免安装 exe 不会删除此目录；卸载安装版也保留数据。
安装包不含任何个人邮箱、授权码、收件人或历史记录。
授权码保存在本机数据文件中，请保管好备份，不要分享给他人。

从旧版迁移：先关闭新旧两个程序。备份新版本 data 文件夹，再将旧版 backend\data
文件夹中的全部内容复制到上述新数据目录（包括 saved_attachments），然后启动新版。
从 3.1 升级时自动保存 before-v3.2.sqlite3 备份；从更早版本升级会保存相应版本备份。
从旧版首次升级会保存 before-v3.sqlite3 备份；旧版已完成任务和发送记录可以查看。
旧版只存内存的未完成任务无法从磁盘恢复。不要同时打开不同版本操作同一份数据。

五、常见问题
无法登录邮箱：确认已启用 SMTP，并使用服务商要求的授权码或应用密码。
QQ 常用设置：smtp.qq.com，端口 465。实际发送需要网络及有效邮箱配置。
本应用采用 SMTP 用户名/密码登录；只允许 OAuth 的组织邮箱需要管理员提供兼容方式。
附件单文件最多 50MB，邮箱服务商实际限制可能更低；可执行脚本和程序附件不受支持。
程序异常：关闭后重新启动；数据目录中的 server.log 可用于排查，提供前检查个人信息。
本构建未配置商业代码签名证书，Windows 可能提示“未知发布者”。请核对来源和 SHA256SUMS.txt。
