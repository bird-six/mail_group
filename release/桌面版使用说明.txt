邮件群发助手 3.2.0 · Windows 桌面版使用说明

一、启动与窗口操作
适用于 Windows 10 / 11 64 位系统，无需安装 Python、Node.js 或配置开发环境。
免安装：双击 MailGroup-3.2.0-x64-portable.exe。
安装版：运行 MailGroup-3.2.0-x64-nsis.exe，完成安装后打开桌面快捷方式。
两种版本使用同一份默认数据，选择其中一种即可，不要同时操作同一份数据。
拖动顶部深色区域可以移动窗口，右上角支持最小化、最大化、关闭及打开数据文件夹。
窗口没有系统原生顶部边框，最右侧滚动条已隐藏，仍可使用滚轮或触控板滚动。
应用内“使用说明”提供目录，可直接跳转到随机模板、邮件汇总等操作章节。

二、第一次群发
1. 打开“邮箱集群”，点击“添加邮箱”，选择邮箱类型，填写邮箱地址、SMTP授权码、
   SMTP 地址和端口。添加后检查账号已启用；编辑时授权码留空会保留原值。
2. 打开“目标邮箱”，单条添加，或在“收件人编辑”中粘贴后点击“解析”。
   支持换行、逗号、分号、邮箱链接和 Markdown 表格，重复地址自动合并。
   检查解析结果、启用状态和“分配预览”；修改输入后必须再次解析才能群发。
3. 打开“邮件内容”，选择“当前编辑内容”，填写主题、正文，选择纯文本或 HTML，
   添加所需附件。此模式可直接发送，无需先保存模板。
   点击“保存”会新增一个包含主题、正文格式和附件的模板，便于以后复用。
4. 回到“首页”，核对内容来源和收件人后点击“开始群发”，会直接创建发送任务。
   点击任务行可查看每位收件人的主题、发送账号、状态及结果。
5. “数据面板”提供发送量、成功率、失败原因和失败邮箱导出。

同一发送账号的相邻邮件间隔为 20～40 秒，多个任务之间也遵守此间隔；不同账号可并行发送。
成功发送的收件人自动禁用，避免再次群发。确需重发时，手动启用指定收件人。
“全部启用”也会重新启用已成功发送的地址，操作前请核对目标。

三、多模板随机发送
1. 在“当前编辑内容”模式下准备邮件，点击“保存”生成模板，可准备多个。
2. 在“选择邮件模板”中勾选多个模板，或点击“全选”，页面自动切换为“随机使用选中模板”。
3. 回首页检查已选模板数量，再点击“开始群发”。每位收件人独立、等概率地抽取一个模板，
   可能重复抽到同一个，不保证平均分配；只选择一个时全部使用该模板。

主题、正文格式和附件始终配套，编辑器中未保存的内容和附件不会混入随机任务。
“清空选择”后无法随机发送。点击“载入编辑”会切回当前编辑模式；修改后“保存”会新增模板，
不会覆盖旧模板。需要继续随机发送时，请重新核对勾选项。
任务创建时会固定每位收件人的模板并保存副本，删除原模板或重启恢复都不会重新抽取。
模板附件加载失败时会阻止发送，请重新载入或改选附件完整的模板。

四、邮件汇总
打开“邮件汇总”，集中查看所有已配置账号的收件箱、已发送文件夹和本应用成功发送的记录。
首次同步远程邮件前，需要按下一节说明开通 IMAP。

1. 点击“同步全部邮箱”；选定单个账号后可点击“同步当前邮箱”。
   每次为每个账号的收件箱、已发送文件夹各补充最多 100 封，优先读取新邮件；
   继续同步可以补全历史。单个账号失败不影响其他账号，关闭群发的账号也会纳入同步。
2. 展开“同步状态与设置”，查看各账号错误、缓存数量、最近同步时间，可点“设置”修改配置。
3. 选择账号、收件/已发送类型，输入主题或往来地址后点击“搜索”，在已同步的邮件中查找。
   使用分页按钮翻页，点击邮件查看正文。首次读取正文需要连接邮箱，已缓存正文可离线查看。
4. “刷新列表”只读取本机记录，获取远程新邮件需要点击同步。
   “本机发送”是本应用成功发送的记录，不依赖 IMAP。可识别的同封远程副本自动合并，
   旧版记录可能同时显示两个来源。服务器接受邮件不代表收件人已最终收到。

列表和正文缓存在本机；查看不会修改原邮箱的已读状态。
HTML 邮件转为纯文本，不加载远程图片；附件只展示名称，请到原邮箱打开。
大邮件最多读取 10 MiB 原始内容、展示 50 万字符，内容截断时会提示。
修改 IMAP 配置或授权码会清理远程同步缓存、保留本机发送记录；
更换邮箱地址或删除账号会移除对应汇总缓存。

五、授权码与 IMAP 设置
以 QQ 邮箱为例，在系统浏览器打开 mail.qq.com 并登录，进入设置中的账号、第三方客户端
或 POP3/IMAP/SMTP 相关选项，开启 IMAP/SMTP 服务，按提示完成验证并生成客户端授权码。
网页入口可能调整，以当前页面提示为准。填入本应用“SMTP授权码”的是授权码，不是 QQ 密码。

QQ 常用发信配置：smtp.qq.com，端口 465，SSL/TLS。
QQ 常用汇总配置：imap.qq.com，端口 993，SSL/TLS。
进入“邮箱集群 → 编辑 → 收发邮件汇总 · IMAP 设置”配置汇总连接。
IMAP 与 SMTP 共用此账号保存的授权码，需确认授权码有对应服务权限。
IMAP 地址留空时根据常见 SMTP 地址自动识别；自定义服务商需手动填写。
如选择 STARTTLS，也需填写服务商提供的对应端口。
“已发送文件夹”默认自动识别；未找到时，填写原邮箱中的文件夹名称后重新同步。
当前支持授权码或应用密码登录，暂不支持仅允许 OAuth 登录的账号。

六、关闭与恢复任务
有活动任务时关闭窗口，会提示“暂停并退出”。确认后等待当前发送返回结果，保留其他未发送项。
重新启动后，在首页已中断任务旁点击“继续未发送”，会重新校验账号及收件人状态，成功项不重发。
异常断电等情况下，“待核对”的邮件可能已经送达；先检查原邮箱或收件方，
确认需要重试后再点击“核对后重试”，以免重复投递。
失败项先检查任务详情和数据面板中的原因，修正后仅为需要重试的收件人创建任务。

七、数据备份与升级
默认数据位置：%APPDATA%\MailGroup\data，以标题栏文件夹按钮打开的位置为准。
备份前关闭应用，复制整个 data 文件夹，保留数据库、模板附件及任务附件。
升级或移动免安装程序不会删除此目录，卸载安装版也保留数据。
数据目录包含授权码、联系人、邮件正文和附件，请勿上传 GitHub 或分享完整备份。
提供日志或截图前，请移除个人邮箱地址、授权码及邮件内容。安装包不包含个人运行数据。

从旧版迁移：先关闭新旧程序，备份新版本 data 目录，再将旧版 backend\data 的内容复制到
新数据目录，包括 saved_attachments 等附件目录，然后启动新版。此操作会使用旧数据替换同名文件。
根据升级前的数据库结构，程序会自动保存对应备份：
- 更早的旧版：before-v3.sqlite3。
- 3.0 版：before-v3.1.sqlite3。
- 3.1 版：before-v3.2.sqlite3。
保留备份并继续使用新版程序，不要同时打开不同版本操作同一份数据。
旧版已完成任务和发送记录可以查看，具备完整内容的成功任务会导入本机邮件汇总。
旧版仅保存在内存中的未完成任务无法从磁盘恢复。

八、常见问题
“开始群发”不可用：检查发件账号和收件人已启用，收件人输入已经解析；当前内容需完整，
随机模式至少勾选一个模板，模板附件需加载完成。
编辑区变灰：正在随机模式，切换“当前编辑内容”或点击模板“载入编辑”即可。
能发信但无法汇总：检查 IMAP 开关、授权码、地址、端口和加密方式，查看账号同步错误。
没有已发送邮件：指定正确文件夹；服务商未保存的副本无法同步，本应用成功记录仍可本机查看。
附件发送失败：单个附件最多 50MB，服务商实际限制可能更低；程序和脚本等类型可能被拦截。
程序异常：关闭后重启。数据目录中的 server.log 可用于排查，分享前先清除个人信息。
本构建未配置商业代码签名证书，Windows 可能提示未知发布者；请核对来源及 SHA256SUMS.txt。
